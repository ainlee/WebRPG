# WebRPG 專案

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![GitHub last commit](https://img.shields.io/github/last-commit/user/webrpg)

現代化 2.5D 網頁角色扮演遊戲框架，整合 WebGL 2.0 與 WebRTC 技術，採用以下核心技術：
- Phaser 3.60 遊戲框架
- Vite 5.0 建置工具鏈
- WebGL 2.0 渲染管線
- WebRTC 點對點連線

## 最新功能 (v2.5.2)
- 動態透視投影系統
- WebRTC 多人連線功能
- 跨裝置響應式介面
- 自動化壓力測試套件

## 快速開始
```bash
git clone https://github.com/user/webrpg.git
cd webrpg
npm install
npm run dev
```

## 開發者指引
1. 安裝依賴：
```powershell
npm install
```

2. 啟動開發伺服器：
```powershell
npm run dev
```

3. 執行測試：
```powershell
npm test
```

## 系統需求
- Node.js 18+
- npm 9+
- 支援 WebGL 2.0 的瀏覽器

## 貢獻指南
歡迎提交 Pull Request，請遵循以下規範：
- 使用 TypeScript 撰寫新功能
- 為所有變更添加單元測試
- 更新對應文件（spec.md, report.md）
- 遵循現有代碼風格
